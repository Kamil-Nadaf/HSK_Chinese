# HSK Practice Sheet

Active-recall practice for HSK 1: flashcards, quizzes, typing, stroke-order writing, sentence building, mock exam and a dictionary. Built around the class lectures; add new words as the course goes on.

**Use it now in the browser:** https://kamil-nadaf.github.io/HSK_Chinese/

## Install

Download the file for your device from the [**Releases**](../../releases/latest) page (Assets).

| Device | File | Steps |
|---|---|---|
| Android | `.apk` | Open it, allow "install from this source", tap Install. |
| Mac | `.dmg` (`arm64` = M1 to M4, `x64` = Intel) | Drag the app to Applications. First time: right-click, Open. |
| Windows | `.exe` | Run it. If SmartScreen warns: More info, Run anyway. |
| Linux | `.AppImage` or `.deb` | `chmod +x file.AppImage && ./file.AppImage`, or `sudo apt install ./file.deb`. |
| iPhone / iPad | none | Open the link above in Safari, Share, Add to Home Screen. |

Progress is saved on each device. Settings, Copy backup moves it between devices.
