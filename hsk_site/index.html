⚡ Grammar Quick-Fire
名词谓语句
No 是 needed for age/date/nationality
我二十岁。/ 今天星期三。
会 vs 能
会 = learned skill · 能 = innate ability / permission
我会说汉语。 / 我能坐这儿吗？
有 / 没有
Place + 有 + sth = there is/are · 没有 drops numbers
桌子上有一本书。
两 vs 二
两 + measure word · 二 in numbers
两个人 (not 二个人)
怎么 + V
how to do something
这个字怎么写？
在 + place + V
doing something at a place
我在学校学习汉语。
方位词
上 下 左 右 前 后 里 外 + 面/边 (+ 的 + noun)
下面的书 = the book below
多少 / 几
多少 = any number · 几 = small number (<10)
多少钱？= how much
了 / 呢
了 = completed/change · 呢 = and…? / where is…?
你呢？= How about you?
不 tone change
不 + 4th tone → bú (不是, 不会, 不好意思)
是 shì · 在 zài · 会 huì
因为…所以…
因为 + reason, 所以 + result
因为太热了，所以我不想去。
比
A 比 B + adj = A is more adj than B
他比我高。
还是
还是 = or (question) · 或者 = or (statement)
你要茶还是咖啡？
是……的
Emphasize time/place/manner of past action · already completed
我是坐飞机来的。/ 你是怎么来的？
认识
To know/meet somebody for the first time
认识你很高兴。
一起
Together · placed before verbs
我们一起去商店。
